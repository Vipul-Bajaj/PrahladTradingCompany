# Prahlad Trading Company

A single-page website for Prahlad Trading Company, an industrial safety equipment and personal protective equipment (PPE) supplier in Raipur, Chhattisgarh, India.

## Website

The page introduces the company and its safety products. Visitors can browse nine product categories; selecting a category opens a dialog with example products and details.

- Head protection
- Foot protection
- Body protection
- Hand protection
- Eye protection
- Respiratory protection
- Welding products
- Fire safety
- Fall protection

The page also includes company background, business hours, and contact information. The figures and business details shown on the website are presented as supplied by the site itself.

## Run Locally

No build tools, package installation, or server are required. Open `index.html` in a web browser, or serve this directory with any static web server.

## Project Files

- `index.html` - Complete website, including its HTML, CSS, product-category data, and JavaScript interactions.
- `README.md` - Project overview and usage instructions.
